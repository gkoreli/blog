# Experiment record

Use the fields the question needs; keep the record readable. Freeze the plan before changing the page or collecting a favorable outcome. Append the result without overwriting the initial hypothesis or failed attempts.

## Before intervention

- Owner worklist, source revision, page and intended reader/operator.
- Actual question and evidence: observed, reported, inferred, or proposed.
- Existing answer and diagnosis; one plausible competing explanation.
- Hypothesis, intervention, primary observable outcome, preservation checks, stop condition.
- Baseline method, timestamp/window, denominator and exact input/output commitments.
- Required access or external inputs; independent work still available.
- Immediate acceptance and any later window, including its actual start condition.

## After intervention

- Exact change, source commit, relevant checks, and rejected alternatives.
- Deployment evidence and actual served behavior, each with its own scope.
- Results against the declared outcome, failures, retries and exclusions.
- Search visibility, AI answer visibility, site access, reader value, and adoption: identify which were measured and which were not.
- Decision, remaining uncertainty, and next bounded action.
- Skill refinement supported by this run, if any.

Use exact values only when observed. Link evidence beside the result. No response and unavailable data are different states.
