# Local full-article passage search comparison

November 14, 2026, America/Los_Angeles. This study uses **local E5-small-v2**, chosen for general passage search, and remains separate from MWG's Gemini-distilled query table. The exact MWG/Gemini blog document index was not built. This experiment does not reproduce the seven-line runtime or its timing.

## Frozen comparison

- Corpus: all 46 local `posts/` publication-source article bodies, including Markdown and isolated SSG rendering of TypeScript posts. No drafts or current-production behavior claim. DOM text extraction excludes navigation, scripts/styles, interactive controls, hidden decoration, SVG/canvas and image-only content. Textual prose, lists, code and tables are retained; every eligible non-whitespace body character is accounted for once.
- Passages: heading-local packing of complete text blocks to 360 tokenizer tokens, allowing a single block up to 480. Larger blocks split without character loss or overlap. Actual input including metadata, E5 prefix and special tokens is checked with truncation disabled; no input may exceed 480 tokens, below the model's 512-token ceiling. Headings supply context; title appears once in the enrichment template. The same enriched passage text feeds keyword and semantic ranking, apart from the model's required passage prefix.
- Model: public `Xenova/e5-small-v2` ONNX revision `02af79985278377e65c724a76275707cb0333c70`, q8, CPU, mean pooling, L2 normalization, 384 dimensions. Transformers.js 3.8.1, two intra-op threads and one inter-op thread. `passage: ` for document inputs and `query: ` for queries. No cloud embedding API or new training. Local model loading disables remote models and rejects fetch calls.
- Conditions: (1) BM25 over the same passages, using the pinned upstream keyword ranker with its plural stemming and stopword rules; (2) E5 dot-product ranking; (3) reciprocal rank fusion of both uncut rank lists at k=60. BM25 returns only passages with positive lexical scores; dense ranking covers every passage. No weighting or cutoff tuning. Return distinct passage IDs at fixed K; multiple passages from one article are allowed. A result score is not a probability of relevance.
- Questions: 36 answerable source-aware agent-authored cases, one short query and one natural-language question for each of 18 article topics, plus eight separately curated expected-no-answer prompts. The author requested that questions be chosen here, rather than supplying user queries. These are not visitor logs or independently human-labeled questions. Previous title-demo probes are outside the scored set.
- Known answer labels: source blocks were selected after reading the articles but before any new full-text rankings. Freeze their mapping into passage IDs before evaluation. Primary metric: at least one known answer passage in the first **three** results. Also record K=1/5/10, reciprocal rank through ten, and known target-article presence. Labels are incomplete: another useful passage may be returned without receiving credit. Do not call this a comprehensive accuracy score.
- No-answer cases: preserve every returned list. No calibrated rejection rule is part of the design; report result admission separately, without treating a high cosine score as answerability or a representative false-positive estimate.
- Repetition: generate the document index once with batch size eight and a content/model/config-keyed local cache. Run all 44 questions in three fresh evaluation processes with fixed seeded order. Repetitions test stability and timing, not 132 independent questions. Keep all failures, norms, full returned ID lists, and timings. No silent model, query, label or ranking changes after the freeze.
- Latency: report model initialization separately from warm query encoding, BM25 ranking, dense scan and fusion. Conditions share the cached corpus/index. Concurrent machine load is uncontrolled; no production Cloudflare or browser inference comparison is claimed.

## Interpretation

Report wins, losses, ties and the short/natural split before selecting illustrative cases. A paired task-cluster bootstrap over 18 source articles is descriptive for this curated set, not a guarantee about real readers or other blogs. Examine every discordant question, retain the original known-answer metric, and keep any post-hoc alternative relevance judgment separate.

Report source/model hashes, passage counts and token ceilings, model/index sizes, document-build time, local query cost and dependencies. No embedding-provider dollar charge exists in this local method; do not invent model-download, electricity, hosting or subscription savings. Asset downloads and local inference are different stages.

Keep full generated source-text captures, cached vectors and raw operational logs outside Git. Public evidence includes methods, IDs, source URLs, hashes, labels, returned ranks, timing and findings. Do not copy raw author messages or personal working notes into artifacts. A local UI may show source passages for the author's review; no public search route or article publication is part of this experiment.

The fixed scripts, labels, corpus/passages digests, model files and runtime lock are recorded in the input freeze before rankings. Preparation fixes to text grouping happened before this freeze; no retrieval results informed them. The earlier MWG studies and metadata demo remain historical and unchanged.
