Try the seven-line embedder on blog titles

Type a short query. The browser loads the real MWG word table, runs the query calculation, and compares the result with precomputed vectors for post titles and tags.

This experiment embeds short metadata with the query table on both sides. It does not implement MWG’s teacher-embedded full-document index. Search quality is exploratory; vector alignment is not a confidence score.

    What is running?

    At build time, this demo embeds each title and its tags with the released query table. At search time, a Web Worker encodes your query, takes dot products, and optionally combines vector rank with literal keyword overlap rank. Descriptions are displayed as snippets and are not indexed. The model files load once; queries run in this page’s worker.

    A full-article version needs article chunks embedded with a compatible document model before publication. The tiny query loop is only one part of that pipeline.
