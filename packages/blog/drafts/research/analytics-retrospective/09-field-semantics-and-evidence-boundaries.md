## Authoritative sources and local responsibilities

Checked October 25 Pacific. Living documentation can change; standards status and dated versions matter. Paraphrases below are deliberately bounded to each source's contract.

|---|---|---|
| [Cloudflare IncomingRequestCfProperties](https://developers.cloudflare.com/workers/runtime-apis/request/#incomingrequestcfproperties), current docs | `request.cf` carries provider network metadata. ASN identifies a network; `asOrganization` names its owner. The source context and redirects affect policy. | [public/_headers](../../../public/_headers) declares this policy. It governs requests originating from those documents, not an external site's incoming assertions. Header configuration is not live header acceptance. An origin-only URL looks like `/`; our parser cannot distinguish an actual homepage source from a source path stripped by policy. |

A cross-site redirect does not automatically explain a later same-origin value. The 124 R1 same-origin/external-referrer cases remain unresolved; neither mismatch nor activation flag identifies an operator. |
| [Fetch forbidden request headers](https://fetch.spec.whatwg.org/commit-snapshots/59afe349913d56898c947576216f1c2579308be7/#forbidden-request-header), October 19, 2026 Living Standard snapshot | Ordinary web Fetch APIs reserve `Referer` and `Sec-` request headers to the user agent. | This browser API protection is not cryptographic authentication of every HTTP sender. **Source-version correction:** the W3C `/TR/referrer-policy/` URL currently serves a January 2017 Candidate Recommendation. Its default-policy discussion differs from the March 2026 Editor's Draft. Do not describe the older document as the current browser default merely because its URL looks canonical. Our explicit configured policy is independently inspectable; actual browser behavior still needs a labelled trial.

## Reproducible local findings

[Probe](probe-field-semantics.mjs) and [saved output with source hashes](field-semantics.json). Run `pnpm -C packages/analytics test`, then `node packages/blog/drafts/research/analytics-retrospective/probe-field-semantics.mjs` from the root. The package's 57 tests passed before this run. The probe uses eleven referrer cases and five simulated network cases, with a capture-only persistence stub. No network, native runtime or database calls. An initial command typo failed before running the probe; the correctly named run passed.

1. Missing and empty headers collapse to absent. External full and origin-only URLs collapse to one hostname. They do not establish an authenticated referring page.
2. An internal full path loses query/fragment as designed. An origin-only internal URL becomes `/`. An unknown internal path stays null. A failed public index lookup also omits unknown article paths through the [route helper](../../../src/worker/referrer-pages.ts); null does not identify which cause occurred.
3. `http://www.gkoreli.com:8080/engineering` is internal under the current hostname-alias rule while its browser origin differs from `https://gkoreli.com`. The rule does not compare schemes/ports. This is a publication-host grouping, not the browser same-origin test. Do not change it silently: decide the intended contract first.
4. `/engineering` and `about:blank` become unusable, just as malformed/unsupported inputs do. Do not label all unusable rows malformed or direct. Adding relative-reference support requires target-URL resolution and a versioned semantic decision, not a blind parser fallback.
5. Native-shaped metadata is taken from simulated `request.cf`, not a client CF-IPCountry header. Nonfinite/missing ASNs become null; finite negative/fractional fixtures pass the present check and receive the request marker. These are adversarial validation-boundary fixtures, not observed Cloudflare outputs or evidence of bad production rows. They show that marker population alone cannot prove a valid ASN range.

The supporting studies and article should distinguish four claims: a field exists; our transformation matches supplied cases; a conforming browser emits the expected value; and production collection covers the intended population. Today's new experiment establishes the second for its bounded cases. The saved audit establishes the first for its window. The latter two remain open.
