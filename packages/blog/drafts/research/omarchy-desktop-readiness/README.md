# Omarchy desktop readiness

Research started November 14, 2026, America/Los_Angeles.

Scope: explain Omarchy's adoption appeal, distinguish Linux execution benefits from desktop integration, inspect current readiness evidence, and compare public user reports with promotional claims.

This research now supports an unpublished article draft. No article publication or machine migration is scheduled. The existing [macOS dependency-install investigation](../../../posts/032-why-worktree-setup-is-slow-on-macos.md) supplies a measured comparison of specific software/storage paths; it does not test Omarchy or Dell hardware.

Method: dated primary documentation and release/code inspection, a purposive qualitative sample of public discussions and firsthand reports, and a subsequent agent-operated VM trial on the existing Mac. Community comments and issue reports can identify experiences and failure modes; they cannot establish population sentiment, adoption, retention, or failure rates. Raw captures and private author material remain outside this repository's Git history.

The web reader could not retrieve the existing worktree article's HTML or Markdown endpoint. Its maintained repository source was read instead; this research does not claim to have checked that article's current production rendering.

Status: source research, first manuscript and the first agent-operated VM experiment are complete. The verification-loop medians were 14.87 seconds on macOS and 14.94 seconds in the VM, with all measured runs accepted. Customization worked with a shell restart and recovery; selected application paths need adaptation. Independent hardware qualification, representative sentiment measurement and author-operated daily-work assessment remain outside this result. Personal requirements and raw prompts remain private. Next bounded action: an ordinary author-operated session in the retained VM, followed by editorial reconciliation of the draft. Publication requires a separate decision.
