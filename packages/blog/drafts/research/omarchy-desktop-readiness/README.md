# Omarchy desktop readiness

Research started November 14, 2026, America/Los_Angeles.

Scope: explain Omarchy's adoption appeal, distinguish Linux execution benefits from desktop integration, inspect current readiness evidence, and compare public user reports with promotional claims.

This is exploratory research. No article publication or machine migration is scheduled. The existing [macOS dependency-install investigation](../../../posts/032-why-worktree-setup-is-slow-on-macos.md) supplies a measured comparison of specific software/storage paths; it does not test Omarchy or Dell hardware.

Method: dated primary documentation and release/code inspection, plus a purposive qualitative sample of public discussions and firsthand reports. Community comments and issue reports can identify experiences and failure modes; they cannot establish population sentiment, adoption, retention, or failure rates. Raw captures and private author material remain outside this repository's Git history.

The web reader could not retrieve the existing worktree article's HTML or Markdown endpoint. Its maintained repository source was read instead; this research does not claim to have checked that article's current production rendering.

## Results

- [Findings and proposed article direction](01-findings.md): product rationale, current release/funding evidence, readiness boundaries, rejected overclaims and a bounded comparison proposal.
- [Public sentiment and source review](02-public-sentiment.md): six directly opened discussion/review sources, inspectable examples and acquisition limitations.

Status: bounded research complete. No Omarchy installation, independent hardware qualification, representative sentiment survey or article manuscript was produced. Public source and code links were checked; raw captures remain in ignored local worklog storage. The next optional action is to choose between a sourced explanatory article and a hands-on comparison. Neither is scheduled by this research.
