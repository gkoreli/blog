## Demonstrated gap

A synthetic one-row local SQLite selection exercises the actual `queryStats` SQL and decoder. Five separate result mutations are accepted by the baseline: removing the headline daily-client count returns zero; replacing a page count with a string returns a zero-count page; removing a page key returns an empty ranking; replacing a series count with a string or removing its bucket produces an all-zero chart. The unchanged headline still says one event. These are controlled decoder counterexamples, not evidence of malformed current production results.

The source helper accepts any finite number, including negative/fractional values, and turns absent or mistyped fields into zero. Several row adapters also silently skip missing keys. Existing signature/native/composition guards are stronger and remain accepted. A bounded frontend review found no additional demonstrated identity/purpose overclaim; keep its current caveats and avoid cosmetic wording changes.
