# Keep access attempts separate from delivered readership

October 31, 2026. Continues [the retained BIC control](03-edge-access-evidence.md) and [TASK-0119](../../../../../docs/tasks/TASK-0119.md).

## Frozen implementation and acceptance plan

Build a dedicated offline analytics export, outside the collector and calibration evaluator. One closed, versioned input contains at most 32 planned attempts and 128 supplied Cloudflare security records. Each executed attempt declares exact method/host/serialized path/query, a UTC half-open join window of at most 60 seconds, its timing basis, operator-label provenance, an optional received response, and an optional scoped collector lookup. A receipt-second window is contextual matching evidence, not a measured execution duration. Reject response or lookup evidence attached to unexecuted attempts.

Bind a provider join to the Ray in a received response. Require exact request context and overlap between the provider timestamp's second interval and the declared join window; the response instant must be inside that window. Ray strings are normalized before input; this module neither strips suffixes nor transforms paths. Multiple candidate attempts leave a security record ambiguous. Multiple records matching one attempt remain multiple supplied records. Duplicate local references reject; repeated facts under different references are surfaced, not silently deduplicated. Same-Ray, time-compatible context disagreements stay distinct from out-of-window reuse.

Keep attempts, responses, supplied security records, scoped collector records and stored kinds in separate denominators. Unavailable or partial empty lookups stay unknown. Only a caller-declared complete scoped lookup can establish zero returned rows in that scope. Nothing here proves Worker non-invocation, population completeness, people, malicious intent, authenticated labels or cryptographic verification. BIC remains a provider action, not an RFC9421 verdict. No classifier confusion matrix is produced.

Return numbered rows and allowlisted categories/counts; omit opaque input references, request context, Rays and arbitrary provider labels. Reject extra fields, malformed clocks, oversized inputs and invalid state combinations. No transport, credentials, raw UA/IP storage, live collection, protection changes, D1 queries or repeated denied request.

Acceptance: replay the actual saved BIC projection and response receipt; expect one executed automation-labelled attempt, one 403 response, one uniquely context-matched BIC block record, and unknown collector/classification stages. Exercise ambiguous joins, event multiplicity, repeated facts, exact path/query mismatches, timing boundaries, missing/partial/complete-empty lookups, unexecuted evidence, private-field rejection and bounded inputs. Run relevant analytics tests/types in isolated output and compare Node/workerd results. Preserve the existing calibration source and original trial grade.

Primary contracts re-read: [Security Events](https://developers.cloudflare.com/waf/analytics/security-events/) (multiplicity and sampled coverage), [Ray IDs](https://developers.cloudflare.com/fundamentals/reference/cloudflare-ray-id/) (non-unique IDs). Original [BIC evidence](edge-access-evidence.json) owns the actual provider observation and capture limits. Caller-supplied inputs are not authenticated by schema validation.

## Results

Delivered the dedicated [`access-evidence` module](../../../../analytics/src/access-evidence.ts) and [input/output contract](../../../../analytics/ACCESS_EVIDENCE.md). It is a separate package export, not a collector import. The [acceptance receipt](access-ledger-checks.json) records all 364 analytics tests, workspace types and 32 exact Node/workerd comparisons (31 synthetic controls plus one actual saved control). Of the 32 inputs, twenty are accepted and twelve reject. These are contract checks, not a traffic sample or an accuracy estimate.

The actual saved request reconciles as **one executed automation-declared attempt, one received 403, one uniquely context-matched BIC block record, and unknown collector/classification stages**. No new request, native observation or database read was made. All fifteen original private archive files verify. The microsecond response receipt is explicitly floored to milliseconds for the input; the original remains intact. Its one-second join window is based on receipt precision, not a measured request duration or proof of synchronized clocks.

Review caught a consequential error: receipt provenance alone had been mapped to automation. The final schema requires a separate operator declaration and accepts a human-operated receipt without relabelling it. A new counterexample test and final source review cover the repair. Controller and attestation pairings are validated, but the parser authenticates neither labels nor captures. The review is not an independent provider oracle.

Missing response/Ray, partial and unavailable lookups, exact request mismatches, half-open timing boundaries, repeated facts and ambiguous allocations remain visible. A block paired with a 2xx response or supplied collector records produces a warning. It does not choose an explanation. The private scope reference points to caller-supplied lookup conditions; even a complete-empty result cannot prove global absence. Stored method stamps are syntactic provenance, not deployed-source authentication.

The collector entry is byte-identical to the baseline: 333,942 bytes, SHA-256 `15eba7182e052858d32b1b7b6338d6958a902d0e20cd5877bffe86b9b4c5a3ff`. The calibration source is unchanged. No site build was needed for this offline export; no served-content, deployment or current production accuracy claim is added. The original failed served check and model-trial grade remain unchanged. The concise published retrospective is unchanged.

Initial local-runtime startup failed because the sandbox denied a loopback socket. The permitted local retry first encountered a stale compiled schema; sequential recompilation followed by the final comparison passed. Both failures are preserved. One final test command ran in the primary checkout and wrote ignored `.test-dist`; the accepted subsequent run is isolated. No `dist/`, server or tracked source was changed by that invocation. The private archive retains 33 files under manifest SHA-256 `29746ac48c4ea75fb00921e85aa7f26398dc6ae990a5a926f018ca36a5e82965`.

**Decision:** use this ledger for controlled access investigations. Do not add security totals to readership or loosen protection from one benign blocked control. Next, inventory retained failed fetcher/calibration receipts for recoverable context and security evidence, reconcile only supported joins, and stop at named capture gaps. New live traffic, D1 queries and extra instrumentation are outside that action. The full goal remains active/incomplete; the native managed-verifier, search-intent, deferred human/device, privacy and historical-purpose inputs keep their existing owners.
