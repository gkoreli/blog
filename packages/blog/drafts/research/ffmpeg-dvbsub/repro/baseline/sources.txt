1. ETSI EN 300 743 V1.6.1 (2018-10), sections 7.2.5, 7.2.5.1, and 10.
https://www.etsi.org/deliver/etsi_EN/300700_300799/300743/01.06.01_60/en_300743v010601p.pdf
Used to check RLE field structure, top/bottom fields, colour mapping, non-modifying
colour semantics, and the distinction between specified default CLUTs and this
decoder's optional reconstruction heuristic. It does not specify this heuristic's
greedy ordering, so preserving that ordering is checked against the source.

The dvbsub section defines compute_clut=-2,-1,0,1. These modes were tested separately.

3. FFmpeg unaligned/native-endian read helpers.
https://github.com/FFmpeg/FFmpeg/blob/aab6cec3e8415154b3f0570f8d131db07a9901de/libavutil/intreadwrite.h
AV_RN64 is an unaligned native-endian read. The block probe uses exact equality,
which is independent of byte ordering, and guards all row extents explicitly.

4. FFmpeg memory API and coding policy.

https://github.com/FFmpeg/FFmpeg/blob/aab6cec3e8415154b3f0570f8d131db07a9901de/doc/developer.texi
