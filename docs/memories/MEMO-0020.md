ADR-0016 replaces the browser-beacon analytics model. The Worker observes successful non-prefetch HTML GET responses; `/api/event` is removed. D1 `page_observations` stores minimized edge observations, 128-bit site/day HMAC client IDs, heuristic browser/bot/AI UA classes, and matched UA rule names. Public stats use stable UTC windows and call the metrics Page views and Daily clients. Legacy `page_views` remains separate and is not queried. Production cutover requires the additive migration and `ANALYTICS_HASH_KEY` secret before deploy.
