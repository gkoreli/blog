gkoreli.com intentionally omits 'unsafe-eval' from script-src. PixiJS 8 generates shader, UBO, uniform, and particle synchronization functions with new Function by default, so a Pixi-backed bundle triggers a CSP violation and may fail at runtime. Every Pixi renderer entry must load `pixi.js/unsafe-eval` before Pixi use. Despite the subpath name, it installs static no-eval polyfills; never solve this by adding 'unsafe-eval' to the site CSP. Verify through Wrangler or another server that applies packages/blog/public/_headers and assert zero securitypolicyviolation events.
