The lab’s first accepted mark language is now semantic geometry, not a shared circle-plus-tail glyph: Ambient Drift uses low-alpha velocity-aligned mint lozenges; Memory Zone uses neutral hollow frames entering from the left and persistent larger amber frames after zone entry; Text Emergence uses upright blue bars tied to glyph sampling; Fracture Pulse uses connected timeline-driven hairline polylines with long silence. All set trail=0. Particle geometry is explicit ParticleMarkDefinition data and Pixi never branches on scene IDs. Basic debugging is framework-owned: stop freezes exact state, renderCurrentFrame redraws without advancing, and stable-ID primitive timeline states/seeks apply only to time-based renderer primitives. This is not particle simulation rewind. The lab exposes an adjacent instrument dock with Freeze/Resume, Restart, Defaults, Stress, exact primitive playhead scrub, metrics, and manifest inspection.
