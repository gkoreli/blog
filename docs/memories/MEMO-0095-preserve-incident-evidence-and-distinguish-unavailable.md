Before repeating a production incident query, read the active task, dated handoff and saved private capture. Keep observed fields and windows explicit: no address in inspected client-error rows does not prove no address in inaccessible provider history, and a shared browser value cannot identify a person. A small successful D1 read establishes only that request; it does not establish report health, quota reset or a billing change. At a break, record completed checks, remaining acceptance evidence and concrete access blockers, link the handoff from the worklist, and commit/push authorized documentation. In-progress tasks mean unfinished work to resume, not a running agent. Working instructions live in AGENTS.md under Operational evidence and session handoffs.
