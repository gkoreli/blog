Extend analyzeScene into bounded structural reads: scene summary, primitive table, dependency graph, ordered pipelines, capability table, seed/frame, current coarse state, and bounded semantic event trace. Define small semantic edits against stable IDs—set emitter rate, replace material channel, insert stage after a named stage, add/remove a transition—then revalidate the whole declaration. Keep SceneDefinition canonical; edits return a new declaration and diagnostics rather than mutating runtime state.

Acceptance: an agent can inspect and patch a scene without reading Pixi code or positional JSON; every edit names semantic IDs, returns deterministic diagnostics, and produces a diffable SceneDefinition; no editor or MCP dependency is required.
