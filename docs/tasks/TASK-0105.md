PROMPT 0012 replaces the frame. The goal is not to exclude automation; it is to name every kind of reader the edge can distinguish, show each honestly, and embrace agent readers (personal AI agents on cloud hosts running Playwright, Cypress, or headless browsers) as an audience. Design the taxonomy from facts the request carries, one reason code per row (GoatCounter model): person-shaped browser navigation from a non-hosting network; navigation-shaped browser from a hosting network (cloud-hosted browser, likely an agent); browser User-Agent without browser request headers (HTTP client); self-declared headless browser (HeadlessChrome, Playwright, etc.); on-demand AI fetchers (ChatGPT-User, Claude-User, Perplexity-User: device-detector category "AI Assistant"); AI crawlers ("AI Data Scraper", "AI Search Crawler", "AI Agent"); search crawlers; feed fetchers, link previews, monitors. Use device-detector's category names and Cloudflare's verified-bot categories as the citable vocabulary. Investigate Web Bot Auth (Cloudflare, IETF HTTP Message Signatures for bots) as the way agents can identify themselves deterministically and be named on the stats page. Every public label must be a fact about the request, never a confidence adjective. This supersedes the Browsers/Browser-like direction in TASK-0102 and feeds its decision; TASK-0101's measurement still gates how header absence is treated.
