# Integrated result

Implemented ADR-0016 as a clean edge-observation cutover. The Worker now serves assets through `env.ASSETS.fetch`, observes eligible HTML responses, and composes analytics as a best-effort side effect. The inline browser beacon and `/api/event` are removed. Analytics is decomposed into eligibility, metadata, traffic classification, daily HMAC identity, repository, UTC window, aggregation, and shared-contract modules. No inheritance hierarchy was introduced because these policies vary independently.

# Parent integration fixes

- Added a browser-safe `@gkoreli/analytics/contracts` subpath so the stats client reuses the public domain contract without importing Worker bindings.
- Narrowed analytics bindings; `ASSETS` belongs to the blog Worker composition root and `handleStats` requires only DB.
- Made missing/empty HMAC secrets fail closed with an explicit diagnostic.
- Made All-time start global to the first public edge observation, independent of traffic/path filters.
- Removed the obsolete legacy table from fresh schema while preserving existing deployments through the additive migration.
- Split combined User-Agent rules so stored rule names match the presented UA (`ChatGPT-User`, `Claude-Web`, `Google-CloudVertexBot`).
- Added SQLite-backed D1 contract tests for metadata minimization, scheduled persistence, missing-secret failure, owner exclusion, half-open bounds, traffic partition reconciliation, full-path totals, zero-filled time series, stable All-time start, and legacy-table isolation.
- Reworked empty selection into one whole-dashboard state; fixed hourly daily-ID units/non-additivity, singular view copy, UA-rule wording, Turnstile wording, 280px chart overflow, and reduced-motion loading.
- Added accurate retention and Cloudflare Web Analytics disclosures.
- Superseded ADR-0004/0005 semantics and updated AGENTS.md current state.
