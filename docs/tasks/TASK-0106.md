## Status (2026-09-03)

Half (1), citable, shipped in 0.5.0 with three deliberate omissions. Shipped: per-post CSL-JSON (`/<slug>.csl.json`) and BibTeX (`/<slug>.bib`), negotiated by `Accept` on the post URL and linked with `rel="alternate"`; a "Cite this" block at the end of every Markdown twin; `rel="license"` to CC BY-NC-ND 4.0 and a `/license` page; the LICENSE clarifications (quoting welcome, code snippets MIT). Omitted, with reasons: Highwire `citation_*` meta tags, because Google Scholar does not index blogs and no AI vendor states it reads them (artifact 05 and 08), so they would be decoration; an ORCID, because no identifier program was chosen (E.2, no DOI); an APA line in HTML, because the plain-text citation line in the Markdown twin covers the agent path and a visible "Cite this" box on the article page is a reader-facing design decision for Goga.

Half (2), "Referenced by", is open. The design question: which sources count as verified. A referrer host in our own database is a claim the client made, not a verified link; Hacker News (Algolia API) and Google Search Console links are verifiable; AI-assistant fetches per post are facts about requests, not citations. Proposal to put to Goga in one message: a per-post panel on `/stats?path=` first (not on the article page), with three labelled rows: verified inbound links (HN, GSC), AI-assistant fetches (ChatGPT-User and peers, from D1), and referrer hosts (self-reported). Nothing is built until he picks the surface.
