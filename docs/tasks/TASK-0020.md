# Legacy-data decision

Production inspection proved the old data was intact and meaningful: 2,564 `page_views` rows from 2026-03-07 through 2026-08-26; 2,120 Browser events / 1,244 daily IDs, 347 Bot events / 324 daily IDs, and 97 AI-UA events / 94 daily IDs; 39 paths, 32 referrers, and 69 countries. No missing hashes or invalid traffic/device classes existed.

The original table remains untouched as the lossless source archive. Added `observation_source` and `source_event_id` to the public read model, then copied every legacy row with:

- `observation_source = beacon`
- source ID retained for idempotency
- traffic classes mapped to browser/bot/ai
- referrers minimized to hostname
- 16-hex daily identifiers duplicated to 32 hex characters, preserving equality/distinct-count behavior without inventing identity
- agent rule left null because raw historical UA was never stored

Backfill proof: source rows 2,564; copied rows 2,564; missing rows 0. Six edge Browser rows existed at verification time. The old table was not modified or deleted.
