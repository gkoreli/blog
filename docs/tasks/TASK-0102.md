## Outcome (2026-09-03)

Superseded in direction by TASK-0105 and closed by release 0.6.0 (commit 3297ff2). The four-pill direction recorded above (Browsers, Bots, AI UAs, All) was not what shipped. What shipped: **Browsers / AI agents / Crawlers / Automation / All**, four disjoint groups of the closed reader-kind set (`READER_GROUPS` in `packages/analytics/src/contracts.ts`), plus a composition table that lists every kind with its reasons. Rationale, from Goga's review ("we need better semantic naming"): group by what the client was doing, not by how confident we are; "Browser-like" and "Bots" were confidence and catch-all words, so they went. The predicate is now `reader_kind IN (...)` per group; the evidence-column predicate from ADR-0016.2 is no longer used for partitioning because ingestion and migrations 0006/0007 assign the kind from the same evidence. Pre-evidence edge rows stay in Browsers as `user-agent-only` unless their reconstructed network is a hosting provider (then Automation as `cloud-browser`), which honours "never lose history" while telling the truth about the rows the raw logs could re-examine. Records: ADR-0016.3 section A ("Public labels"), AGENTS.md Stats dashboard row, CHANGELOG 0.6.0, `docs/adr/0016.2` is redirected rather than amended.
