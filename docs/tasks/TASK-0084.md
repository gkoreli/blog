# Method

Created `packages/blog/scripts/omp-research-footprint.ts`. It reads the exact root OMP JSONL and every child JSONL in its same-named agent directory. OMP usage is per assistant response, so each response is counted once. Public input is normalized as non-cached input + cacheRead + cacheWrite; total must equal normalized input + output; reasoning must be a subset of output. A separate root session—including the parallel animation work—is excluded.

The manifest records every included session ID, parent ID, agent path, response count, last usage line/time, per-session normalized totals, and SHA-256 commitment to each private log prefix. Private logs are not committed. Readers can inspect the public artifact manifest and session commitments, but cannot reconstruct totals without the private logs.
