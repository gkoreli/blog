## Actual reader flows

The live [search page](https://gkoreli.com/search) served the ordinary GET form, native dialog and explicit model opt-in. A live related query about moving symbols for Svelte returned Radar #01 and its source explanation. Clicking opened [the actual paragraph](https://gkoreli.com/oss-radar-01-vercel-winter-2026-cohort#passage-c1a1899b18fa3a73), whose target highlight was visible. Cmd+K then opened word search on the live article and returned the Moving Icons paragraphs. Raw HTTP also confirmed fully rendered word results without relying on client execution.

Local browser checks covered arrow/Enter navigation, Escape/scroll release, explicit focus return, literal `/` inside editing, rapid query changes, in-article empty results, themes, model failure recovery and words during a delayed model load. A deliberately retired old-vector URL recovered through the new manifest with one request per old/new vector file and only the original two model-part requests. The 390-pixel layout used a real CSS-viewport iframe, not a mobile-device performance simulation. The own-browser WebKit host's Tab-navigation limitation remains documented; no universal accessibility pass is claimed.

These are different payload boundaries. Low-end-device memory and latency, relevance for independent readers, calibrated no-answer behavior and third-party adoption remain unestablished.
