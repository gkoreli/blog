Goal: evolve @gkoreli/animation from truthful lab v1 into a deterministic, inspectable, agent-native framework that can produce stronger museum-piece scenes without coupling the package to the blog.

Build order:
1. deterministic fixed-frame execution, replay, and frame snapshots
2. compiled executable plans and a renderer-facing batch/view boundary
3. measured hot-path allocation removal and explicit performance budgets
4. Text Emergence V2 as the next visually undeniable scene
5. injected choreography inputs and coarse state/event traces
6. one selective article-preamble pilot only after the runtime earns it

Guardrails: keep SceneDefinition canonical and text-diffable; stable semantic IDs; structured diagnostics; time/randomness as inputs; Pixi isolated; no editor, MCP server, general ECS, or dependency adoption before deterministic inspection exists; no animation on default pages; prefer fewer real experiments to fake breadth.
