# ADR-0016.16: Label and isolate production collection-stage trials

## Status

Prepared October 27, 2026 UTC. [Native local Worker evidence and production worklist](../../packages/blog/drafts/research/edge-vs-rum/08-production-stage-protocol.md) own acceptance. Extends [client-form claims](0016.15-client-form-claims.md) and the existing TASK-0120 calibration scope. Human operation, actual JavaScript-off, physical devices and Cloudflare beacon ingestion remain separate measurements.

## Decision

Add an off-by-default calibration route, rather than enable broad raw diagnostics or infer stage failures from counter ratios. A maximum fifteen-minute `ANALYTICS_CALIBRATION` configuration registers at most 32 UUID trials with closed planned conditions and operator labels. Every page, asset, stage write and receipt requires the same request's current-day owner mark. Inactive/expired/invalid configurations do no trial database work. The mark is based on existing daily pseudonymous inputs; it is an exclusion gate, not strong administrator authentication or proof of a human.

Only this guarded route passes `verifiedOwnerExclusion` to the existing collector after verifying the mark. The collector persists `is_owner = 1`, preserving exclusion even if the daily mark is later removed. Ordinary requests cannot obtain this option from headers or query text. Collection version becomes `2026-10-27.6`; classifier `.5`, signature verifier `.4`, report shape and normal collection rules remain unchanged. Trial pages exercise the actual Worker/collector. Receipt/API/assets do not create page observations.

Migration 0016 adds an indexed experiment-counter table. Retain only trial ID, closed planned condition/operator, expiration, response-preparation count and script/attempt/queue-result/beacon counters. No additional UA, addresses, cookies, device probes or diagnostic activation. Trial paths join to routine excluded observations, so these records are not claimed anonymous. Earlier rows and their classifications remain intact.

Counters distinguish responses prepared, client-reported script/attempt/queue outcome, server-received beacon requests and actual stored observations. Missing rows can mean pending work, failure or interruption; no failure verdict is manufactured. Planned operator labels require independent execution evidence. A browser-controlled agent, a human operating a browser, a UA declaration and physical hardware are different facts.

Use native D1 for shared state across isolates/data centers; do not infer missing receipt from an isolate's memory or per-colo cache. Counter updates are atomic and bounded at four page responses and eight reports per stage/trial. Require same-origin POSTs and an exact tiny body; do not store caller free text. No page/receipt caching. CSP conditions selectively block scripts or the local beacon while leaving stage/receipt endpoints available. Neither condition is relabelled an actual browser JavaScript-off setting.

HTTP receipt access ends with activation expiry and requires the current mark. Counters become deletion-eligible 24 hours after activation ends; the existing nightly cron removes up to 1,000 expired rows per invocation. Read expiry, deletion eligibility, actual cleanup and ordinary excluded-observation retention are distinct. No new recurring automation or general reader telemetry is enabled.

## Acceptance and remaining limits

Apply migration before source. Check fail-closed activation/ownership, origin/body/count limits, real collector persistence, permanent exclusion after mark removal, native Worker/D1/crypto, script syntax, non-JS receipt and native expiry SQL. Then accept source activation, off-mode behavior, temporary configuration, actual marked browser/curl controls, persisted stages/classifications and cleanup of temporary bindings separately.

Human labels require a human's execution evidence; configuration alone supplies none. The first-party beacon does not prove Cloudflare Web Analytics receipt. CSP cannot explain historical loss prevalence. IP/UA changes can lose the daily mark and prevent a trial; record that as a failed precondition, not a missing reader. Existing linked-row retention/lawful-basis questions remain open, and broad diagnostics stay off.
